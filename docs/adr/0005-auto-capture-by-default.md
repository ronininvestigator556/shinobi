# Auto-capture every visited page by default

Within an open Case, Shinobi captures every page the operator visits **automatically** (archive HTML + screenshot + rendered text + metadata) rather than requiring a manual "capture" action. This inherits the prior tool's most valuable behavior: evidence is never lost to a forgotten click, and completeness matters for investigative work.

To bound the obvious downside — recording privileged, personal, or irrelevant pages — capture has a **visible pause** and a **per-Identity on/off**, so the operator can stop it deliberately before browsing something that shouldn't be in the case.
